# Remote Jobs Board

A real job aggregator pulling live jobs from free APIs.

## Features
- Real jobs from Remotive API & Arbeitnow API
- Search by title, company, skills
- Filter by category (Remote, Engineering, Design, etc.)
- Job detail pages with JSON-LD schema
- Apply Now button
- Mobile responsive

## Deploy on Vercel

1. Push to GitHub
2. Go to vercel.com
3. Import repo
4. Click Deploy

## Local Setup

Just open `index.html` in browser - no server needed!

## APIs Used (All Free)
- Remotive API: https://remotive.com/api/remote-jobs
- Arbeitnow API: https://www.arbeitnow.com/api/job-board-api
